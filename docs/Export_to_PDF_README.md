### Export the resume to PDF (Chrome or Edge)

1. Open `docs/Pratham_Vaghela_Resume.html` in your browser.
2. Press Ctrl+P (Print).
3. Destination: Save as PDF.
4. Pages: All; Layout: Portrait.
5. Paper size: A4; Margins: Default (or None).
6. Options: Enable "Background graphics" for proper line rules and typography.
7. Click Save and name the file `Pratham_Vaghela_Resume.pdf`.

### Optional tweaks
- Update LinkedIn and GitHub links in the header to your actual URLs before exporting.
- You can adjust font size by changing the `font-size` on `body` in the HTML to fit one page if needed.
